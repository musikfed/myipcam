# MyIPCam OS 3.1 — T23/T23N, загрузка IP-камеры с microSD

**MyIPCam** — экспериментальный локальный проект прошивки и веб-администрирования IP-камеры на базе **Ingenic T23/T23N**. Текущая тестовая аппаратная база — плата **GV-T23-PTZ-MAIN-V2.0**.

Цель проекта — получить автономную IP-камеру без обязательной привязки к облаку: загрузка с microSD, локальный Wi-Fi, аппаратное H.264-видео, PTZ, собственная веб-панель и в дальнейшем минимальная специализированная MyIPCam OS.

> Текущий статус: **Stage2 / аппаратная тестовая сборка**. Это ещё не финальная минимальная MyIPCam OS.

## Что уже проверено на реальной камере

- загрузка системы с **microSD**;
- работа платы без использования SPI NOR как активного загрузочного носителя;
- нативный режим microSD **1-bit MMC**;
- подключение по Wi-Fi;
- сенсор **SC2336**;
- Wi-Fi-модуль **AltoBeam ATBM6012BX**;
- аппаратное кодирование **H.264**;
- управление PTZ через **ULN2803LV** и motors-daemon;
- загрузка и работа собственной веб-панели **MyIPCam**.

## Проверенная аппаратная конфигурация

- плата: `GV-T23-PTZ-MAIN-V2.0`;
- ревизия/дата платы: `20230915`;
- SoC: Ingenic T23/T23N;
- сенсор: SC2336;
- Wi-Fi: AltoBeam ATBM6012BX;
- драйвер PTZ: ULN2803LV;
- исходная SPI NOR: PUYA P25Q64SH, 64 Mbit / 8 MB;
- microSD: CLK/CMD/DAT0, режим 1-bit MMC;
- совместимый донорский профиль: `galayou_g2_t23n_sc2336_atbm6012bx`.

Название Galayou G2 означает только совместимый программный профиль и не является подтверждением розничной модели камеры.

## Текущая схема загрузки

```text
T23 BootROM
 -> SPL / U-Boot на microSD
 -> Linux
 -> ext4 rootfs на microSD
 -> Wi-Fi / ISP / H.264 / PTZ
 -> MyIPCam Web UI
```

## Что ещё предстоит

- собственный минимальный MyIPCam backend;
- полноценные настройки микрофона и динамика;
- архив и запись на свободное место microSD;
- WireGuard / AmneziaWG по требованию;
- удаление лишних сервисов и уменьшение rootfs;
- оптимизация live-view, чтобы убрать лишнюю нагрузку HTTP/curl-прокси;
- дальнейшее уменьшение полного образа с текущих 85 MiB.

## Для чего проект

Проект может быть полезен тем, кто работает с IP-камерами на Ingenic T23/T23N, embedded Linux, SC2336, AltoBeam, PTZ, загрузкой с SD-карты и локальными системами видеонаблюдения без облачной зависимости.

Ключевые слова для поиска: MyIPCam, IP-камера T23, Ingenic T23N, прошивка камеры на SD, microSD boot camera, SC2336, ATBM6012BX, PTZ, локальная IP-камера, embedded Linux camera.
